# 📋 Setup Checklist

Use this checklist to track your progress setting up the Gamified Learning Platform.

## Prerequisites ✅

- [ ] Python 3.8+ installed (`python --version`)
- [ ] Node.js 16+ installed (`node --version`)
- [ ] npm installed (`npm --version`)
- [ ] Code editor ready (VS Code recommended)
- [ ] Two terminal windows available

---

## Backend Setup ✅

- [ ] Navigate to backend folder
- [ ] Create virtual environment (`python -m venv venv`)
- [ ] Activate virtual environment (`.\venv\Scripts\Activate.ps1`)
- [ ] Install dependencies (`pip install -r requirements.txt`)
- [ ] Copy environment file (`Copy-Item .env.example .env`)
- [ ] Initialize database (run Python command from QUICKSTART.md)
- [ ] Start backend server (`python run.py`)
- [ ] Verify backend running at http://localhost:5000

**Backend Status**: ⬜ Not Started | ⬜ In Progress | ⬜ Complete

---

## Frontend Setup ✅

- [ ] Open new terminal window
- [ ] Navigate to frontend folder
- [ ] Install dependencies (`npm install`)
- [ ] Copy environment file (`Copy-Item .env.example .env`)
- [ ] Start development server (`npm start`)
- [ ] Verify frontend opens at http://localhost:3000
- [ ] See login page displayed

**Frontend Status**: ⬜ Not Started | ⬜ In Progress | ⬜ Complete
